# Native Side Chat

The plugin contributes a `dsh-side-chat` tab kind and an order `-20` guide entry through the public right-sidebar registry. Its single child slot owns the embedded `conversation.content` Factory occurrence. No core files, private UI context, direct model endpoint, or global main-session selection is changed.

Each conversation view mounts under a keyed, independently retained official Session reference. The view never replaces the reference while mounted. Closing the view releases only its Client reference; it does not cancel Host execution or delete a session. History is displayed without unmounting the conversation, preserving its draft. An explicit rename holds its own temporary reference through completion.

New chats inherit only the main session's working directory and use the Host defaults. Context is copied only by the explicit official fork action. The native composer owns submission, streaming, model controls, attachment intake, permissions, approval, cancellation, and message presentation.

Browser persistence contains session IDs and navigation metadata, not messages or credentials. Failed writes retain the in-memory navigation index and surface a notice. Browser origins have independent history indexes; official session logs remain the durable transcript authority.

The browser bundle's only runtime externals are React and its JSX runtime. Lucide glyphs are bundled. The build rejects additional unregistered browser externals. Production profiles reference a separately unpacked built release, not the development checkout's `lib` directory.

Validation includes nine focused history/creation tests, TypeScript, a browser-safe production bundle, and the real DSH Web assembly with a deterministic test-only LLM adapter. Browser scenarios exercise streaming, cancellation, rename, searchable/pinned history, explicit context forking, independent native tabs, refresh restoration, and a 390-pixel viewport. The fixture is excluded from the published package and never mounted in production profiles.
