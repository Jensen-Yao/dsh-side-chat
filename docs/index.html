在熟悉的工作流里，多一个空间

轻量接入，原生协作

让支线有自己的位置。

Side Chat 复用 Harness 的会话能力和界面控件，专注解决一件事：让你探索新问题时，主对话依然保持清晰。

独立会话，多标签切换

同时保留几条思路。新建侧聊不会替换主会话，也不动主聊天草稿。

01

沿用 DSH 原生聊天能力

使用官方会话组件和 composer。模型、附件、工具、授权和停止操作仍由 Harness 管理。

02

历史可找，刷新可续

搜索、置顶、重命名。刷新页面后恢复标签索引；移除索引不会删除 Harness 会话。

03

需要时，从主线分支

通过官方 fork 操作显式带入接口支持的上下文，是否分支由你决定。

04

两步接入

把侧聊放进你的 DSH。

需要 DeepSeek Harness 0.2.1-rc.2 或更新且兼容公开侧栏与会话 UI 接口的版本。

  1. 在插件市场或插件设置中安装以下 GitHub 版本。
  2. 在当前 profile 启用 DSH Side Chat，按提示重新加载。
github:Jensen-Yao/dsh-side-chat#v0.1.0
  1. 在桌面应用自己的插件市场或插件设置中安装此版本。
  2. 启用插件并按 Harness 提示重新加载桌面 profile。
github:Jensen-Yao/dsh-side-chat#v0.1.0

通过命令行安装依赖后，还需在 profile 的 bundle 列表保留现有项目并加入 dsh-side-chat。桌面版使用自己的插件管理界面。

数据与权限

你的会话，仍由 Harness 管理。

消息和任务记录保存在 DSH 官方会话服务中。浏览器只记录恢复标签所需的会话 ID 和少量标签元数据，历史索引按页面 origin 隔离。

关闭标签不会取消后台任务，移除历史索引不会删除会话。Side Chat 不携带额外 API 密钥、不直连模型，也不会自动扩大权限。

常见问题

开始前，了解这些。

侧边聊天会复制主会话内容吗？

不会自动复制。需要承接上下文时，使用聊天工具栏中的 fork 操作；复制范围由 DSH 官方 fork 接口决定。

关闭侧栏或标签会删除会话吗？

不会。关闭或收起侧栏不会删除会话。移除 Side Chat 历史项只清除恢复索引，Harness 的会话记录仍保留。

任务还在生成时可以关闭标签吗？

可以，但关闭标签不会停止任务。返回该会话后，使用原生停止按钮结束生成。

桌面版和 Web 会共享侧聊历史吗？

浏览器历史索引按 origin 隔离，因此 Web 与桌面窗口不自动共享标签记录。各自能访问的 Harness 会话仍由 DSH 保存。
